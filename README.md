# PhaseComp Plugin

## English Description

⚠️ **WARNING:** This plugin currently works only as a VST3 on **Windows**. Support for other platforms may come in future updates.

This plugin offers compression with phase inversion and a **sidechain** input to control the compressor’s detection path.

### Functionality:

- **Phase Inverter:** Inverts the signal phase before compression.  
- **Compressor:** Features controls like threshold, ratio, attack, release, and knee. It also handles gain reduction metering.  
- **Sidechain Support:** Use an external source to drive the compressor. A parameter toggles external vs. internal routing.  
- **Output Gain:** Adjusts the final volume level of the processed signal.

### How to Use:

1. Place the PhaseComp plugin file into the folder `C:\Program Files\Common Files\VST3`.  
2. Refresh your DAW’s plugin list to detect the new PhaseComp plugin.  
3. Insert PhaseComp on a track in your DAW.  
4. Configure compressor settings (threshold, ratio, etc.) as desired.  
5. Enable the **Sidechain** input if you want to compress based on an external signal.  
6. Check the final **Output** gain for level adjustments.  
7. If you encounter issues, please open an issue on GitHub or contact me on Instagram. See links at [this page](https://ponte-dsp.fly.dev/).

## Descrizione in Italiano

⚠️ **ATTENZIONE:** Questo plugin attualmente funziona solo come VST3 su **Windows**. Il supporto per altre piattaforme potrebbe arrivare in futuri aggiornamenti.

Questo plugin offre compressione con inversione di fase e un ingresso **sidechain** per controllare il percorso di rilevamento del compressore.

### Funzionalità:

- **Phase Inverter:** Permette di invertire la fase del segnale prima della compressione.  
- **Compressor:** Include parametri di soglia, ratio, attacco, rilascio e knee, e mostra la riduzione di guadagno.  
- **Supporto Sidechain:** È possibile usare una sorgente esterna per pilotare il compressore. Un parametro permette di scegliere tra routing interno ed esterno.  
- **Output Gain:** Controlla il livello finale del segnale elaborato.

### Come Usarlo:

1. Copia il file del plugin PhaseComp nella cartella `C:\Program Files\Common Files\VST3`.  
2. Aggiorna l’elenco dei plugin nella tua DAW per rilevare il nuovo PhaseComp.  
3. Inserisci PhaseComp su una traccia nella tua DAW.  
4. Configura i parametri del compressore (soglia, ratio, ecc.) secondo le tue esigenze.  
5. Abilita l’ingresso **Sidechain** per comprimere in base a un segnale esterno.  
6. Controlla il guadagno di **Output**.  
7. Se riscontri problemi, apri una issue su GitHub o contattami su Instagram. Trovi tutto a [questo link](https://ponte-dsp.fly.dev/).
